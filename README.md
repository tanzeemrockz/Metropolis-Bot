## So this is slack bot I made for the stardance mission *Making a Slack Bot*
A slack bot built using **Slack Bolt (python)** and **Groq** for AI Inference

---

## Features 

* **/metropolis-ask `<prompt>`**: Query the `openai/gpt-oss-20b` model entirely from within slack
* **/metropolis-whoami**: View your username
* **/metropolis-scan**: Gather active user info in real time

---

## Tech Stack

* **Language**: Python 3.10(+)
* **Framework**: `slack-bolt`, `slack-sdk`
* **LLM Inference**: `groq`
* **Hosting**: Hack Club Nest on Debian 13
